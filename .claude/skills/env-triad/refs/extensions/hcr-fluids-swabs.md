# hydrocarbon resources-fluids_swabs

Fluids and swabs from hydrocarbon reservoirs.

Interface class `HcrFluidsSwabsInterface`. No curated value set — ENVO expansion is the only grounding available.

## Where candidates come from

This extension has expansion subtrees for `env_medium`. Run:

```bash
uv run python .claude/skills/env-triad/scripts/envo_lookup.py pool "hydrocarbon resources-fluids_swabs" env_medium
```

to see them with definitions and descendant counts, rather than relying on this file.

## Evidence in the sample record

Reservoir, well, and production language. Fluid or swab sampling distinguishes this from the cores extension.
