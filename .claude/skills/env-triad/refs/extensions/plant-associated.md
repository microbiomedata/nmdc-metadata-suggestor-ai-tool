# plant-associated

Plant tissue and the plant's immediate environment.

Interface class `PlantAssociatedInterface`. Curated value set: 72/62/28 values for env_broad_scale / env_local_scale / env_medium.

## Where candidates come from

Prefer the curated value set, which the **schema-context** skill supplies.
Beyond it, expansion runs over the slot's anchor class.

## Evidence in the sample record

`host_name`, `host_taxid`, and the plant part named in `samp_name`. The medium is usually plant tissue, not soil.
