# water

Water column samples, marine through freshwater.

Interface class `WaterInterface`. Curated value set: 56/86/96 values for env_broad_scale / env_local_scale / env_medium.

## Where candidates come from

Prefer the curated value set, which the **schema-context** skill supplies.
Beyond it, expansion runs over the slot's anchor class.

## Evidence in the sample record

`depth`, `lat_lon`, salinity and tidal language, and `samp_name` naming a water body.
